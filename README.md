# Personal Growth Workbench

A single-file personal workbench for daily study planning, content creation,
and lightweight life tracking.

## Privacy

The page has no backend. Each visitor's task checks, notes, and life records
are stored only in that visitor's browser through LocalStorage. This repository
does not contain any saved personal records.

## Local Development

Open `index.html` directly in a modern browser.
